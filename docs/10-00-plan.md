# Plan

## Purpose

This plan records current and future owner work for `tool.scad-project`.
Released history belongs in [../CHANGELOG.md](../CHANGELOG.md).

## Current position

The current main line contains the canonical generic `update.*` ownership
cleanup from issue #107 and is being prepared for the next SCAD-tool baseline
used by Migration 011.

Documentation standardization is tracked by
[issue #110](https://github.com/brainboxemb/tool.scad-project/issues/110).

The paused v0.15.11 release preparation is intentionally rebuilt only after this
documentation structure is qualified on current main.

## Working priorities

When changing this tool:

1. keep generic repository mechanics in `tool.git-project`;
2. keep SCAD project/build/design/verification semantics here;
3. keep runtime implementation in the qualified SCAD toolchain image family;
4. keep consumer workflow callers thin and released;
5. preserve direct and SCons behavior where both are supported;
6. retain exact evidence for release-visible contracts.
