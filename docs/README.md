# tool.scad-project documentation

This directory is the documentation entrypoint for `tool.scad-project`.

The tool owns shared SCAD project behavior: project configuration, build/design/
verification semantics, reusable SCAD workflows, publication policy and SCAD
producer evidence. Generic repository mechanics belong to `tool.git-project`.
